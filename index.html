Part D — Explain What You Learned

1. What does the action attribute do?

The action attribute specifies the URL or location where the form data will be sent after the user submits the form. It tells the form where to send the information after it is submitted.

2. What does the method attribute do?

The method attribute specifies how the browser sends the form data to the destination. Common methods are GET and POST.It tells the browser how to send the form information to the server.

3. Why is GET commonly useful for a search form?

GET is useful for search forms because the search information is added to the URL as a query string. This makes search results easy to bookmark or share.It is useful for search forms because it shows the search information in the URL, making it easy to share or save the search.

4. Why might POST be used for a registration form?

POST sends form data in the request body instead of putting it in the URL. It is commonly used for registration because the form may contain personal information. The server must still process and protect the data properly.It is used for registration forms because it sends the information in the request body instead of showing it in the URL.

5. Does using POST automatically make information secure? Explain why or why not.

No. POST does not automatically make information secure. HTTPS is needed to encrypt data while it travels between the browser and server, and the website must also handle and store the information securely.
